💡 1 unit 3D = 1 mm. Rotasi dalam derajat (0-360).

📥 Import File STL

📦
Tap untuk pilih file .stl
(ASCII atau binary STL, dalam mm)
ℹ️ Info:
• STL otomatis di-scale ke mm (asumsi sudah mm)
• Diletakkan di tengah lantai
• Bisa diputar/di-scale/gabung dengan objek lain
• File besar (>5MB) mungkin lambat di HP lama

📱 Panduan Kontrol

  • 1 jari drag — Putar kamera
  • 2 jari — Zoom & geser kamera
  • Tap objek — Pilih objek
  • Tap kosong — Batal pilih
  • 🎮 D-Pad — Geser objek (X/Y/Z) dengan step 0.5/1/5/10 mm
  • ↻ Rotasi — Mode rotasi + panel rotasi muncul (X/Y/Z, step 5/15/45/90°)
  • Ukuran — Ubah ukuran, posisi, rotasi, toggle lubang
  • Lubang — Toggle cepat lubang
  • Gabung — Tap A → tap B → Gabung
  • 📥 Import STL — Tombol kanan atas
  • ↶ Undo — Batalkan (maks 5)
