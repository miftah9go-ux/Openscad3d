💡 1 unit 3D = 1 mm. Rotasi dalam derajat (0-360).

📥 Import File STL

📦
Tap untuk pilih file .stl
(ASCII atau binary STL, dalam mm)
ℹ️ Info:
• STL otomatis di-scale ke mm
• Diletakkan di tengah lantai
• Bisa diputar/di-scale/gabung dengan objek lain
• File besar (>5MB) mungkin lambat di HP lama

📄 Import OpenSCAD

📜
Tap untuk pilih file .scad
ℹ️ Info:
• File OpenSCAD (.scad) akan dikonversi menjadi objek 3D.
• Mendukung perintah dasar seperti `cube`, `sphere`, `cylinder`, dan `difference` (lubang).

📱 Panduan Kontrol

  • 1 jari drag — Putar kamera
  • 2 jari — Zoom & geser kamera
  • Tap objek — Pilih objek
  • 🎮 D-Pad — Geser objek (step 0.5/1/5/10 mm)
  • ↻ Rotasi — Mode rotasi + panel rotasi
  • 📐 Ukuran — Ubah ukuran, posisi, rotasi
  • ⧉ Duplikat — Gandakan objek
  • 🕳️ Lubang — Toggle status lubang
  • ✂️ Potong — Terapkan lubang secara permanen (CSG)
  • ⊕ Gabung — Gabungkan dua objek solid
  • 📥 Import STL / SCAD — Tombol atas
  • 💾 Export — Tombol atas (STL atau SCAD)
